🌬️ Bengaluru Air Quality Analysis Dashboard

Statistical Analysis & Predictive Modelling using Classical Regression and Machine Learning Techniques

Phase 1: Classical Regression & Assumptions | Phase 2: Model Selection & Comparative Evaluation

Project Overview

Location: Bengaluru, Karnataka, India
Target Variable: PM2.5 (µg/m³)
Objective: Predict PM2.5 using regression and ML techniques
Dataset: KSPCB Hourly Air Quality Reports

PHASE 1 Classical Regression and Estimator Validation

Exploratory Data Analysis

Multiple Linear Regression - Model & Coefficients

PM2.5 = Intercept + β₁(PM10) + β₂(NO) + β₃(NO2) + β₄(SO2) + β₅(CO) + β₆(Ozone)

See results/mlr_coefficients.csv and results/mlr_summary.txt for detailed coefficients

Assumption Testing

Multicollinearity: VIF analysis - see results/vif_results.csv
Heteroskedasticity: Breusch-Pagan test conducted
Autocorrelation: Durbin-Watson test conducted
Normality: Residual distribution analysis
